# Contributing

Thanks for contributing to SMM Turk Panel.

## Guidelines

- keep pull requests focused
- document database/schema changes
- include screenshots for UI changes
- test authentication, payment, and order flows carefully
- never commit secrets, production data, database dumps, or real customer information

## Pull requests

Explain:

1. the problem
2. the implementation
3. how it was tested
4. deployment or migration impact

For security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
